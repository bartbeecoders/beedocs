Add page changes tracking on documents.
This can be enabled by the owner of the document.
A nr of copies parameter can also be set. 0 indicates unlimited copies.
When enabled, you should keep each version of the document and the user should be able to pull up that document.

For documents that are changed tracked, wait a little bit longer before create a saved copy. The suto save of the document saves it quite often. So now you get a lot of tracked changes. Improve this.
